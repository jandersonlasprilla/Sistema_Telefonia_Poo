# Sistema_Telefonia_Poo

Proyecto de POO en Java: encapsulamiento, herencia y métodos get/set.

## Estructura
- LineaTelefonica.java : clase padre
- LineaPrepago.java    : hija (descuenta del saldo)
- LineaPostpago.java   : hija (límite de crédito y factura)
- Main.java            : ejecución y pruebas

## Cómo ejecutar
javac *.java
java Main
